Poland 1939-1945 - interactive map (offline copy of the website)

Browsers won't run this folder's index.html straight from disk, so start the
small local server included here:
  Windows:      double-click start.bat
  macOS/Linux:  run ./start.sh in a terminal
It opens http://localhost:8000/ in your browser (needs Python 3 or Node.js).

No Python or Node? Download poland-ww2-map.html from the same release instead:
it's the whole app in one file, and double-clicking it just works.

The base map tiles come from OpenStreetMap, so an internet connection is
needed to see the map background. Event data is bundled.
